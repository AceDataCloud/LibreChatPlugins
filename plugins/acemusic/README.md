# ACE Music for LibreChat

From a checkout containing this package run `python3 scripts/install.py acemusic --plugin-dir /path/to/LibreChat/plugin` and restart the instance. Select **ACE Music** in the instance MCP settings and sign in to Ace Data Cloud to authorize access. Each user connects their own account. [Installation guide](../../README.md) · [中文](../../readme/README_zh_Hans.md)

Inspect the models before creating media. Generating songs or lyrics and importing reference audio are billable operations. Covers use one owned platform audio ID and mashups use two. Save the original task ID for authenticated free retrieval. [Service pricing](https://platform.acedata.cloud/services/acemusic)
