# Privacy and cost

The packages store no credentials. LibreChat manages each user's OAuth session or separately configured personal MCP Token. The existing hosted MCP receives the user's inputs and required credential, and forwards the selected service request through Ace Data Cloud. Files/prompts/outputs may contain personal content; submit only data you are permitted to process. Review the current Ace account terms/privacy and the hosting administrator's policy. Do not place secrets in plugin files, chat prompts, screenshots or exports.

The plugin source is free. Model and media API calls follow the current service price and the user's permissions/balance. Connection checks and a static guide do not prove a generation will succeed. No automatic generation retry or fallback is introduced. Use one task ID for retrieval and verify its bill separately.
